# 새 작업 생성

사용자의 요청과 제공 자료를 바탕으로 새 작업을 바로 이어갈 수 있는 최소 구성을 만든다. 먼저 [하네스 공통 지침](../../../AGENTS.md)을 읽는다. 이 파일이 위치한 하네스의 루트를 경로 기준으로 삼으며, 메타 스킬 실행만으로 현재 채팅의 메인 업무를 바꾸지 않는다.

## 생성 전 확인

- 요청에서 작업명, 담당 역할·범위, 목표·완료 기준·핵심 조건과 맥락 자료를 파악한다. 명확한 내용은 그대로 적용하고, 명시되지 않은 목표는 미정으로 둔다. 이름을 정하지 않았다면 역할에 맞는 간결한 식별자를 정해 보고하되, 업무의 정체성이나 대상이 모호하면 필요한 내용만 확인한다.
- 대상은 `tasks/{작업명}/`와 `.agents/skills/task_{작업명}/SKILL.md`다. 작업명은 단일 경로 요소로 사용하고, 실제 경로와 기존 작업 목록·동명 스킬을 먼저 확인한다.
- **작업 폴더에 메모리·코드·자료·산출물 등 진행 중이거나 이미 수행한 작업의 흔적이 있으면, 아무것도 변경하지 않고 “이미 만들어진 작업”임을 보고하고 생성을 종료한다.** 누락된 메모리·스킬·목록 항목도 이 호출에서 자동 보완하지 않는다.
- 기존 폴더가 비어 있으면 사용할 수 있다. 비어 있지 않지만 작업 여부가 불명확하거나, 동명 스킬·등록 정보만 남아 있으면 기존 내용을 보존하고 상태와 필요한 확인을 보고한다. 비슷한 이름의 다른 작업을 임의로 재사용하지 않는다.
- 제공 자료는 실제로 읽고 출처와 확인 범위를 남긴다. 초기화에 필수인 자료를 읽지 못하면 파일 생성 전에 보고하고 해당 내용에 의존하는 초기화를 보류한다. 자료의 주장·사용자 결정·추론을 구분한다.

## 새 작업 구성

기존 작업이 아님을 확인한 뒤 아래 파일을 만든다. 하네스 공통 지침의 내용을 복제하기보다 해당 업무에 필요한 차이만 구체화한다.

| 경로 | 작성 내용 |
| --- | --- |
| `.agents/skills/task_{작업명}/SKILL.md` | `name: task_{작업명}`과 업무 선택에 도움이 되는 `description`, 작업 페르소나·담당 범위, 정확한 작업 루트와 아래 진입 절차 |
| `tasks/{작업명}/AGENTS.md` | 업무별 목표와 수행·검증·보고 절차, 필요한 입력과 산출물·품질 기준. 지속적으로 적용할 지침을 두고 현재 진척도는 메모리에서 관리 |
| `tasks/{작업명}/MEMORY.md` | 장기기억·단기기억·작업 내역을 구분한 기억 원본 |
| `tasks/{작업명}/MEMO.md` | 세 구획을 고르게 요약한 독립적으로 이해 가능한 재개용 문서 |
| `tasks/{작업명}/STRUCTURE.md` | 해당 작업 루트를 `.`로 삼는 실제 연구 파일 트리와 역할 설명. 하네스 운영 파일은 제외 |

생성하는 작업 전환 스킬에는 다음을 명시한다.

- 하네스 루트의 AGENTS.md와 작업 목록을 먼저 확인하고, 지정한 작업 루트의 AGENTS.md·MEMO.md·STRUCTURE.md를 읽는다.
- 해당 작업의 지침을 하네스 공통 지침과 함께 적용하며, 상세 맥락이 필요하면 MEMORY.md의 관련 기록을 조회한다.
- 필요한 작업 스킬은 하네스 루트의 `.agents/skills/{작업명}_{스킬명}/SKILL.md`에서 읽는다. 실제로 존재하고 필요한 스킬만 적용한다.
- 현재 채팅에서의 업무 유지·전환과 타 업무 위임은 하네스 공통 지침을 따른다. 다른 업무의 기억·구조·결과는 필요한 범위에서 참조할 수 있다.

## 맥락 초기화와 등록

- MEMORY.md의 장기기억에는 확인된 목표·완료 기준·핵심 조건·중요한 결정과 이유를, 단기기억에는 현재 요청·확인된 상태·미해결 문제·다음 행동을 적는다. 작업 내역에는 초기화 내용과 반영한 자료·출처를 남긴다.
- 제공 자료에 과거 작업이 기록되어 있으면 출처와 함께 반영하되, 실제로 실행하거나 검증한 것처럼 바꾸지 않는다. 모르는 내용·시각은 추정하지 않는다.
- MEMO.md는 MEMORY.md를 근거로 목표·조건·현재 상태·다음 행동·주요 결정과 이력을 요약하고, 반영한 원본의 갱신 시각을 표시한다.
- 기록 시각은 실제 확인한 `YYYY-MM-DD HH:mm:ss KST`를 사용한다. 과거 사건의 발생 시각이 불명확하면 현재 기록 시각과 구분한다.
- STRUCTURE.md에는 실제로 존재하는 해당 작업의 연구 파일만 적는다. 등록 대상이 없으면 그 상태를 명시한다. 작업 밖의 제공 자료는 MEMORY.md에서 실제 위치를 연결하고, 작업 안에 있는 것처럼 트리에 넣지 않는다.
- 제공 자료를 임의로 이동하거나 원본을 수정하지 않는다. `work/`·`results/`는 실제 저장할 산출물이 있을 때 공통 지침의 용도에 맞게 사용한다.
- 생성이 완료된 작업만 하네스 루트 AGENTS.md의 작업 목록에 한 행으로 등록한다. 작업 루트는 `tasks/{작업명}/`, 전환 스킬은 `task_{작업명}`으로 적고, 다른 행은 보존한다.

## 완료 확인과 보고

생성한 파일의 존재·이름·경로 연결, 전환 스킬의 frontmatter, 메모리와 요약의 일치, 구조 안내와 실제 파일, 작업 목록을 확인한다. 사용자 지정의 밑줄 명명 규칙을 임의로 하이픈으로 바꾸지 않는다.

생성된 작업과 호출할 작업 전환 스킬, 반영한 자료·확인 범위, 미정·보류 사항을 짧게 보고한다. 생성 도중 실패했다면 생성된 파일과 미완료 항목을 구분해 보고하며 완료로 등록하지 않는다. 새 업무의 실제 수행은 사용자가 요청한 범위에서 시작한다.
